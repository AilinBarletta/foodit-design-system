Cómo leer esta documentación

Los componentes usan solo variables de core-semantic.css, más espaciados y tamaños de global-primitives.css. Nunca se referencian --foo-* directamente: siempre se pasa por Core. Cuando un valor no tiene token en Figma aparece un /* TODO: token no definido en Figma */.

  • Orden de carga: global-primitives.css → foodit.css → core-semantic.css → components.css.
  • Marca y modo viven en <html>: data-brand="foodit" y data-mode="dark".
  • Cada ejemplo muestra los data-* que lo definen. Los estados se muestran forzados (data-state="hover" / .is-hover) además de los pseudo-clases reales (:hover, :focus-within, :disabled).
  • Las tablas de tokens resuelven el valor computado en vivo: al cambiar el modo oscuro se actualizan.

2. Button

variantsolid | outline | ghost

colorprimary | secondary | accent | subscription | error | black | white

size48 | 40 | 32

statedefault | hover | loading | disabled

isOnlyIconancho = alto (data-only-icon)

íconosopcionales a izquierda (.ds-btn__icon) y derecha

Medidas y tokens

  • Radio --components-button-radius. Borde (outline) --components-button-weigth.
  • Padding horizontal: 48 → --p-20, 40 → --p-12, 32 → --p-8. Gap: --gap-8 (32 → --gap-4).
  • Ícono: 48 → --size-20, 40 → --size-16, 32 → --size-12.
  • Alto: 48 → --size-48, 40 → --size-40, 32 → --size-32.
  • Texto en mayúsculas, bold, interlineado 1: 48 → --text-label-lg, 40 → --text-label-md, 32 → --text-label-sm.
  • Solid: fondo --bg-{color}-default, texto --text-{color}-foreground; hover --bg-{color}-light; disabled --bg-{color}-lighten.
  • Outline: borde --border-{color}-default, texto --text-{color}-default; hover -light; disabled -lighten.
  • Ghost: texto --text-{color}-default; hover --bg-{color}-default-opacity-15 (black → --bg-black-999-opacity-15, white → --bg-white-1-15); disabled --text-{color}-lighten.
  • Loading: spinner en lugar del contenido, mantiene el ancho.

Markup

<button class="ds-btn" type="button"
        data-variant="solid" data-color="primary" data-size="48">
  <span class="ds-btn__icon" aria-hidden="true">…svg…</span>
  <span class="ds-btn__label">Guardar</span>
</button>

<button class="ds-btn" data-variant="ghost" data-color="black"
        data-size="32" data-only-icon aria-label="Imprimir">
  <span class="ds-btn__icon" aria-hidden="true">…svg…</span>
</button>

3. Input

labelTypefloating | fixed

colordefault | gray | error

size56 | 48

stateenabled | hover | focus | disabled (error sin disabled)

íconosopcional izquierda/derecha con separador vertical

supporting textcon ícono opcional (.ds-field__supporting)

Medidas y tokens

  • Radio --components-input-radius, borde --border-sm, padding horizontal --p-12, gap --gap-8.
  • Alto: 56 → --size-56, 48 → --size-48. Texto del campo: --text-label-lg (56) / --text-label-md (48).
  • Label y supporting text --text-label-sm; gap entre label fijo y campo --gap-4.
  • Floating: en focus o con valor sube sobre el borde superior con fondo --bg-neutral-1 (en gray: --bg-neutral-50).
  • Default: borde --border-base-light; hover --border-base-default; focus --border-base-dark (2px, vía --border-2).
  • Gray: fondo --bg-neutral-50. Error: borde --border-error-* y texto --text-error-default; hover -light; focus -dark.
  • Disabled: borde --border-base-lighten, texto --text-base-lighten. Placeholder: --text-base-light.

Markup

<!-- floating: el label va DENTRO del control, después del input -->
<div class="ds-field" data-label-type="floating" data-color="default" data-size="56">
  <div class="ds-field__control">
    <span class="ds-field__icon ds-field__icon--start" aria-hidden="true">…svg…</span>
    <input class="ds-field__input" id="q" type="search" placeholder=" ">
    <label class="ds-field__label" for="q">Buscar</label>
  </div>
  <p class="ds-field__supporting">Texto de apoyo</p>
</div>

<!-- fixed: el label va FUERA del control, arriba -->
<div class="ds-field" data-label-type="fixed" data-color="gray" data-size="48">
  <label class="ds-field__label" for="mail">Email</label>
  <div class="ds-field__control">
    <input class="ds-field__input" id="mail" type="email" placeholder="tu@email.com">
  </div>
</div>

6. Alert

typesuccess | info | warning | error | skeleton

stylelight | solid

estructuraícono circular (--size-24) + título + descripción + slot

radio--components-alert-radius

padding / gap--p-16 / --gap-8

textotítulo bold --text-body-lg; descripción --text-body-sm

  • Light: fondo --bg-{type}-lighten, borde --border-{type}-default, título --text-{type}-default, descripción --text-base-default.
  • Solid: fondo --bg-{type}-default, texto --text-{type}-foreground.
  • Ícono circular: light → fondo --bg-{type}-default + glifo --text-{type}-foreground; solid → fondo --bg-{type}-foreground + glifo --text-{type}-default (el spec no define los colores del ícono: decisión documentada).
  • Skeleton: bloques --bg-skeleton, borde --border-skeleton.
  • Títulos de ejemplo: “¡Listo!”, “Información”, “¡Atención!”, “¡Uppps!”.

Markup

<div class="ds-alert" data-type="error" data-style="light" role="alert">
  <span class="ds-alert__icon" aria-hidden="true">…svg…</span>
  <div class="ds-alert__body">
    <p class="ds-alert__title">¡Uppps!</p>
    <p class="ds-alert__desc">Descripción del problema.</p>
    <div class="ds-alert__slot">…acciones…</div>
  </div>
</div>
