Design System La Nación — Core

Foodit · tokens y componentes

Esta carpeta contiene el Design System de La Nación exportado de Figma. Los archivos de tokens no se modifican: se consumen tal cual.

  1. global-primitives.css — [BASE] Primitive (Global).
  2. foodit.css — foundations de la marca (--foo-*).
  3. core-semantic.css — tokens de Core (los que usan los componentes).
  4. components.css — componentes de design-system-spec.md.

Documentación Catálogo de tokens (color, tipografía, espaciados, radios) y de cada componente con todas sus variantes y estados.

Abrir docs.html

Prototipo Pantalla de Foodit (detalle de receta) armada solo con los componentes: chips, botones, input de búsqueda, alert y toast.

Abrir prototipo

Marca y modo se definen en <html>: data-brand="foodit" y, para modo oscuro, data-mode="dark". El switch de arriba agrega o quita ese atributo.
